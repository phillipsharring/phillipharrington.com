Colophon for phillipharrington.com My CMS is Just HTML... Kinda

This website is static HTML built with Vite, Tailwind, and handlr-build, a small build package of mine that swaps custom HTML tags for plain HTML at build time.

The "Kinda" part is those custom tags: I write things like <lnk>, <heading>, and <spaced> instead of repeating the same markup on every page. Rule of thumb: any HTML with Tailwind classes on it lives in a component, and the rest is plain old HTML. I wrote about it in HTML is Fun Again.

To write an article, I typically dictate my thoughts into Notes on my phone then edit at the computer. To publish it, I simply make an HTML file in my content/pages directory, and the build script handles the rest. When it's that simple, you'd think I would publish more often 😂

The code for this site is on GitHub, and so is handlr-build, if you're curious.

Abstract URLs

The abstract URLs, e.g. /about, are HTML files without an extension containing the rendered output. During the build, I apply system metadata in the S3 bucket so they have Content-type: text/html applied to them and will render in the browser. No SPA. No routing or anything. But the pages load fast as fuck-all get-out, so it's just as good.

Locally I develop with the Vite dev server, which handles live-reload and serves the abstract URLs the same way production does: no extension, no trailing slash, no redirect. A small Vite plugin from handlr-build renders each page on the fly from the source files in content/pages.

A TailwindCSS Convert, Finally

The site uses TailwindCSS. The notion of using it with a team and having a common framework for CSS is what sold me, so I'm using it here, too. It's honestly one less thing to worry about. No Sass/SCSS builds, no stylesheets to maintain, just utility classes. CSS: solved.

Other than the JS hamburger menu script, which I never update, all I have to do is write content. It's refreshing.

Hosting is Just S3

The site is served from an AWS S3 bucket with a CloudFront distribution in front of it. (And even that seems like an extravagance, when I could just as easily slap this mother onto GitHub pages and put Cloudflare in front of it.) I also use AWS for the SSL certificate and domain name. No database. No server-side junk (one tiny Lambda for comments doesn't count). No container.

It's all open source: this site and handlr-build, both on GitHub.
