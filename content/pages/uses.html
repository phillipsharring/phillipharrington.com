Uses This is a Uses page

Several people inspired me to make one. Make sure to check out uses.tech for a list of everyone's /uses pages. If I ever get a single person asking about the software or hardware I use, I'll send them the link to this page.

In General...

I try to install as little software as possible, in favor of using containers to run stuff. No web or db servers are installed on my machine. Anything I genuinely need installed, I get from Homebrew, so it stays updated.

Editor + Terminal

I've let my license for PHPStorm expire, and I'm relying on Claude more often, so I don't need all that PHP power. Anything I have to actually look at or edit, like the writing I'm doing now, I can handle in VS Code. Claude has helped tremendously, not only with code but with more esoteric questions, like "What would Jakob Nielsen say?" It even helped me reorganize this very website.

Desktop Apps

Lately I've been using Google Chrome for development as well as regular browsing on my desktops and phone. The rest is other standard developer stuff. iTerm2 (w/ Josean Martinez's great tips on making it awesome ). For local dev, my basic-services containers handle the database, Adminer, Mailpit and an Nginx proxy, so I don't need a DB app. I occasionally use Postman for HTTP stuff. I'm off Adobe for image editing, preferring the free and open source Inkscape.

I use Espanso for text expansion, which is cross-platform.

Desk Setup

My main computer is my own, beefy MacBook Pro, which I use for everything except my day job, where they've issued me an annoying Windows machine. Otherwise, I'm pretty much off Windows and Linux at the moment, and at my age, hopefully for the remainder...

The old Mac mini M1 is still on my desk, too. I haven't found a job for it lately.

My monitor is a 32" curved Samsung. It's pretty big, but I'd like the 40" eventually, to get that "wrapped around my head" feeling back. At least with one monitor, I'm not constantly trying to level them.

My desk is a motorized adjustable sit/stand number that I got from a company that was selling them cheap. It was a great deal. I rarely stand. I should do that more often.

Other Gear

I use Bose QuietComfort Ultra headphones pretty much all day. They fixed the few issues I had with my old pair of QC 35 ii headphones. If you can manage it, get a pair of these babies.
