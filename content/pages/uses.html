Uses This is a Uses page

This is a Uses page, which I was inspired to make by several people. Make sure to check out uses.tech for a list of everyone's /uses pages. If I ever get a single person asking about the software or hardware I use, I'll send them the link to this page.

In General...

I try to install as little software as possible, in favor of using containers to run stuff. No web or db servers are installed on my machine.

Editor + Terminal

PHPStorm. I've started using VS Code almost exclusively for everything besides PHP. I had been using VS Code from time to time but it's not as great at PHP as PHPStorm is, no offense. I still use it to edit a few projects, though, including this website.

And Claude Code, which helped me reorganize this very website.

Desktop Apps

Lately I've been using Google Chrome for development as well as regular browsing on my desktops and phone. The rest is other standard developer stuff. iTerm2 (w/ Josean Martinez's great tips on making it awesome ). For local dev, my basic-services containers handle the database, Adminer, Mailpit and a proxy, so I don't need a DB app. Postman for HTTP stuff, Photoshop & Illustrator for graphics, but I typically only renew the subscription for a couple of months out of the year, when BSides RDU needs updates.

Espanso for text expansion. I still haven't gotten around to configuring it, but the config is in my dotfiles, waiting.

Desk Setup

My main computer is my own, much beefier MacBook Pro, which I use for everything, day job included. I'm pretty much off Windows and Linux at the moment, and at my age, hopefully for the remainder...

The Mac mini M1 is still on my desk, too. I haven't found a job for it lately.

My monitor is a 32" curved Samsung. It's gigantic and forms a huge, all-consuming curve around my head.

My desk is a motorized adjustable sit/stand number that I got from a company that was selling them cheap. It was a great deal. I rarely stand. I should do that more often.

Other Gear

I use Bose QuietComfort Ultra headphones pretty much all day. They've fixed the few issues I had with the old pair of QC 35 ii headphones I had. If you can manage it, get a pair of these babies.
