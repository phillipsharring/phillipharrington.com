Types of Types Phillip Harrington

Variables, Types and strict_types said every value has a type, and Operators showed what happens when PHP juggles them. This lesson goes through the types themselves. Most are what you'd expect. One of them, the float, is quietly wrong about money, and it's the one people reach for first.

The Types int

A whole number: 42, -7, 0. On a 64-bit machine, which is nearly all of them, it goes up to PHP_INT_MAX, a little over nine quintillion. Go past it, and PHP hands you a float instead. Ints are exact: adding and subtracting them never drifts.

float

A number with a fractional part: 3.14, 0.5, 1e3. Floats cover a huge range, and they're the right tool for measurements, averages and science. But they're stored as binary fractions, and most decimal fractions, like 0.1, have no exact binary form. So they're stored as the nearest value that fits, which is slightly off. 0.1 + 0.2 is 0.30000000000000004.

bool

true or false. Any value can be read as a bool, in an if, and these count as false: false, 0, 0.0, '', '0', an empty array, and null. Everything else is true, including the string 'false'.

string

Text, or more exactly, a row of bytes. Strings and Text and UTF-8 are both about it, because the difference between bytes and letters matters as soon as someone types "café."

array

A list, or a set of named values, or both: ['a', 'b'], ['name' => 'Alice']. Arrays has the details.

null

No value. It's what a variable holds before it's set, what a missing database field comes back as, and what ?? looks for. In a type declaration, ?string means "a string, or null."

object

A value that carries its own functions, called methods. PHP comes with many, like DateTimeImmutable for dates: (new DateTimeImmutable('2026-11-27'))->format('l') is "Friday." You'll make your own in Classes and Objects.

The Rest

A few types show up mostly in declarations: callable (something you can call like a function), iterable (something you can loop over), mixed (anything), void (a function that returns nothing). And int|string means "an int or a string": a union type.

In 1982 the Vancouver Stock Exchange started a new index at 1,000. Less than two years later it stood at about 520, in a market that hadn't fallen. The index was recalculated thousands of times a day, and each time the result was cut off at three decimal places instead of rounded. Tiny losses, every time, all in the same direction. Recalculated properly, it was over 1,000. How It Works

Why a float can't hold a dime, and what to do about it:

  1. A float is stored in binary, as a fraction made of halves, quarters, eighths and so on.
  2. One tenth can't be made from those exactly, any more than one third can be written exactly in decimal (0.333...).
  3. So 0.1 is stored as the closest binary fraction, a hair off.
  4. Each sum carries the error forward. Add a dime ten times, and you get 0.9999999999999999, not 1.
  5. Ints don't have this problem. Count money in the smallest unit, cents, as an int: ten dimes are 100, exactly.

So: floats are not for money. Store and add up cents as ints, in your code and in your database, and turn them into dollars only when you show them to a person. When you need fractions of a cent, like interest or tax rates, use a decimal library, such as PHP's BCMath extension, which works in decimal digits instead of binary.

In PHP
  • get_debug_type($x): the type's name, like int or DateTimeImmutable.
  • is_int(), is_float(), is_string(), is_bool(), is_array(), is_null(): one question each.
  • PHP_INT_MAX: the biggest int.
  • intdiv() and %: splitting cents without leaving the ints.
  • number_format($cents / 100, 2): cents to dollars, only for display.
  • round($float, 2) rounds for display. It doesn't make a float exact.
    •  Gotchas
  • Never compare floats with ===. 0.1 + 0.2 === 0.3 is false. Compare the difference to a small tolerance, or, better, don't use floats for anything you need to compare exactly.
  • Money in a float column is the same mistake, in the database. Use an integer column for cents, or a DECIMAL column, never FLOAT or DOUBLE.
  • Prices from input are strings. '19.99' from a form isn't a float yet, and shouldn't become one. Never trust input: check it, and convert it to cents carefully, digit by digit, not by multiplying a float by 100.
  • '0' is false, and 'false' is true. If a form sends '0' for "no," if ($value) works by luck. Compare to what you expect, with ===.
    • In February 1991, a Patriot missile battery in Dhahran, Saudi Arabia, failed to stop an incoming Scud missile, and 28 American soldiers were killed. The system counted time in tenths of a second, and a tenth has no exact binary form, so its clock drifted. After about 100 hours running, it was off by about a third of a second, enough to look in the wrong place for the missile. A government report traced the failure to that rounding.
