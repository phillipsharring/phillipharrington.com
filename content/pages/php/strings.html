Strings Phillip Harrington

A web app is mostly text going in and out: names, emails, comments, URLs, the HTML itself. In PHP, text is a string, and PHP has more functions for strings than for anything else. You need about a dozen of them most days. This lesson is those, and the ways of writing a string down.

What's a String?

A row of bytes, usually text. PHP doesn't care what the bytes are, so a string can hold a name, a whole HTML page, or the contents of an image. For text, those bytes are nearly always UTF-8, where one letter can take more than one byte. Text and UTF-8, next, is about that. This lesson sticks to plain English, where a byte and a letter are the same.

Single and Double Quotes
  • Single quotes mean exactly what you typed: 'Hello, $name\n' is those characters, dollar sign and backslash included. Only \' and \\ are special.
  • Double quotes fill things in: "Hello, $name\n" puts the value of $name in, and \n becomes a new line. Wrap the variable in braces, "{$count} items", when it's next to other letters or it's an array item, like "{$order['id']}".

    • Use single quotes unless you want something filled in. Then nobody has to wonder whether a $ is meant.

    Heredoc and Nowdoc

    For several lines, a heredoc: <<<TEXT, the lines, then TEXT;. It follows double-quote rules. A nowdoc, <<<'TEXT', with the marker in single quotes, follows single-quote rules. Indent the closing marker, and that much indent is taken off every line.

    The heredoc comes from the Unix shell, where <<EOF means "the input is right here, in the script, until a line that says EOF." It's been in shells since the Bourne shell of the late 1970s. Perl borrowed it, and so did PHP. The name is just that: a document that's here. How It Works

    Nearly every string from outside goes through the same few steps:

    1. It arrives as input: a form field, a query string, a header, a line in a file.
    2. You check it's a string at all, then clean it: trim() takes the spaces off both ends, because people paste them in.
    3. You test it: not empty, not too long, the right shape. str_contains(), strlen() and friends, or filter_var() for things like email addresses.
    4. You work with it: change case, replace, split, join.
    5. You send it out, escaped for wherever it's going: htmlspecialchars() for HTML, a prepared statement for SQL.

    Steps two and three are the ones people skip. Never trust input: a string from outside can be empty, a megabyte long, full of HTML, or not a string at all.

    Try It

    The quotes, a heredoc, and the everyday functions. In a folder, make strings.php:

    docker run --rm -v "$PWD":/app -w /app php:8.4-cli php strings.php

    Match each line of output to the line that made it. The first shows single quotes leaving $name\n alone. The email, typed with stray spaces and capitals, comes out trimmed and lowercased. And the sprintf() line shows its patterns at work: %-8s pads a string to eight on the right, %6.2f rounds to two decimals in six spaces, and %03d pads a number with zeros.

    In PHP
  • trim(), ltrim(), rtrim(): take whitespace off the ends.
  • strlen(): the length, in bytes.
  • str_contains(), str_starts_with(), str_ends_with(): yes-or-no questions, since PHP 8.0.
  • strpos(): where something is, or false. Compare with !== false, as in Documentation.
  • str_replace($find, $replace, $text): every match, replaced.
  • substr($text, $start, $length): a piece.
  • strtolower(), strtoupper(), ucfirst(): case.
  • explode($separator, $text) and implode($glue, $array): split and join.
  • sprintf(), str_pad(), number_format(): laying things out.
  • htmlspecialchars(): on the way into HTML, every time.
    •  Gotchas
  • '\n' isn't a new line. In single quotes it's a backslash and an n. You want "\n".
  • These functions count bytes, not letters. strlen(), substr() and strtoupper() are fine for English and wrong for "café." The next lesson has the functions that count letters.
  • A string from input might not be a string. ?name[]=x makes $_GET['name'] an array, and trim() on an array is a TypeError. Check with is_string() first, as the Forms example does.
  • Don't build HTML or SQL by gluing input into strings. Escape it for HTML, and put it in a prepared statement for SQL. Gluing is how XSS and SQL injection happen.

    • sprintf() can say which argument goes where: %1$s is the first, %2$s the second, and you can use one twice or out of order. sprintf('%2$s, %1$s', 'Ada', 'Lovelace') is "Lovelace, Ada." It's what makes one pattern work in languages that put words in a different order.

    Everything here assumed one byte is one letter. For "café," "naïve," or anyone's name that isn't English, it isn't. Next: Text and UTF-8.
