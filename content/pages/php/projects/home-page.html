Home Page Phillip Harrington

The lessons are done. From here on, you build things. The first one is the page most sites start with: a home page. It's mostly HTML, with just enough PHP to do what plain HTML can't: greet the visitor by the time of day, build a list from data, and keep the year in the footer right without you ever touching it.

Every project after this one adds to the same habits, so they start here: the code lives in a project folder, only public is served, and anything PHP prints into the page gets escaped.

What You'll Use
  • Document Root: serving only public.
  • PHP Files, Escaping into PHP, and phpinfo() and Output: mixing PHP into HTML.
  • Variables, Types and strict_types and Arrays: the data the page is built from.
  • Modern PHP: match.
  • XSS and Escaping Output: htmlspecialchars() on the way out.
    • Build It The Folders

    Make a project folder, and in it a folder called public. That's the web root. Everything in this project is small enough to live in public, but start the habit now: later projects keep their code and settings outside it.

    What each piece is doing:

  • The data comes first. The name, the about line and the links sit at the top, in variables and an array. The HTML below only arranges them. Change a link, and you change one line, not a tag in the middle of the markup.
  • The greeting. date('G') is the hour, 0 to 23, and match (true) picks the first line that's true.
  • The footer. date('Y') is this year, worked out on every request, so the copyright line is right on January 1st with nobody awake. filemtime(__FILE__) is when this file last changed, which makes an honest "Updated" date.
  • Everything printed is escaped. The name and links are yours today, but data has a way of coming from somewhere else later: a settings file, a database, a form. htmlspecialchars() costs nothing and makes that safe when it happens.

    Run It

    From the project folder, serve public:

    docker run --rm -it -p 8000:8000 -v "$PWD":/app -w /app php:8.4-cli php -S 0.0.0.0:8000 -t public

    Open http://localhost:8000. Then look at what the browser actually got:

    curl http://localhost:8000

    Plain HTML, with the greeting, the year and the links filled in, and not a trace of PHP. The browser never sees your code, only what it printed. Reload a few hours later, and the greeting changes on its own.

    New to Docker or the terminal? Tools has the setup.

    Gotchas
  • The server's clock may not be yours. Containers and most servers run on UTC, so "Good morning" can arrive at 9 p.m. Set the time zone on purpose, with date_default_timezone_set() or date.timezone in the settings, and say which one on the page if it matters.
  • A page that ends in .php isn't always run. Open the file straight from your disk, by double-clicking it, and the browser shows the raw code or downloads it. PHP only runs when a server hands the file to PHP. Always go through http://localhost:8000.
  • Forgetting charset. Without <meta charset="utf-8">, a browser may guess the wrong encoding and show accented letters as junk. Text and UTF-8 has the whole story.

    • filemtime(__FILE__) gives every page an "Updated" line that's always true, with nothing to remember. Readers trust a page more when they can see it's been looked after, and you'll stop finding "Updated 2019" on a page you changed last week.
