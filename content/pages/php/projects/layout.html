Layout Phillip Harrington

Useful Includes ended with a header that opens <main> and a footer that closes it. That works until someone edits one half and not the other. A layout turns it inside out: one file holds the whole page around the content, start to finish, and each page is just its own content, dropped into the middle.

You'll build a render() function that runs a template and hands back what it printed, a layout that wraps every page, and one entry point that picks the page, or a 404 that looks like the rest of the site.

What You'll Use
  • Output Buffering: catching what a template prints, instead of sending it.
  • Useful Includes: the bootstrap, settings and helpers, carried over.
  • Single Point of Entry: one index.php answering every path.
  • Separating Concerns: pages that hold content, a layout that holds the page.

    It does three things. extract() turns the array's keys into variables, so a template can say $title instead of $vars['title']. ob_start() starts catching output, the template runs, and ob_get_clean() hands back everything it printed, as a string, without sending any of it. Because the template runs inside a function, nothing leaks in from the page that called it: it gets the variables you passed, and none of the caller's.

    Gotchas
  • Never extract() input. extract($_GET) lets any visitor create or overwrite your variables by adding them to the URL. Only extract arrays you built yourself. EXTR_SKIP is a second guard: it won't overwrite a variable that already exists.
  • Never let the request name the template. render($_GET['page']) is the view source trap again: a path built from input. Look it up in a list you control.
  • A 404 page still needs a 404 status. A friendly "not found" page sent with 200 OK tells search engines it's a real page, and they'll keep it. Set the code before you render.
  • Headers come before content, still. Because the page renders into a string first, nothing is sent until the final echo. That's a bonus: a template deep in the page can't trigger "headers already sent," and you can still change the status after rendering.
    • Early PHP had a setting called register_globals that did what extract($_REQUEST) does, for every request, before your code ran: add ?admin=1 to a URL and your script had a variable $admin set to 1. It was switched off by default in PHP 4.2, in 2002, and removed entirely in PHP 5.4, in 2012.

    Let each route carry its own page title, as $routes does here, and have the layout put it in <title>. Browser tabs, bookmarks and search results all show it, and a site where every tab says the same thing is hard to find your way around.
